# Compromised Email Checker (CEC)

CEC is a OSINT (Open Source Intelligence) tool designed to help security analysts and individuals identify if their email addresses have been compromised in known data breaches. It leverages the **XposedOrNot API** to provide detailed reports on data exposures.

## 🛠️ Installation

1. **Clone the repository**:
   ```bash
   https://github.com/JoaquinPicazoV/Compromised-Email-Checker.git
   cd Compromised-Email-Checker
   ```

## 💻 Usage

Run the main script to start a scan:

```bash
python main.py
# OR
py main.py
# OR
python3 main.py
```

Follow the on-screen prompts to enter the email you wish to investigate.
